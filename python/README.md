# Python

Mes exercices de Python, rangés par chapitre : un dossier par chapitre, un fichier par exercice.
Chaque exercice n'utilise que les notions vues jusqu'à son chapitre.

```bash
cd python/02_boucles
python3 01_parcourir_une_liste.py
```

| Dossier | Notions |
|---------|---------|
| `01_affichage/` | `print`, variables, f-strings, `input`, division euclidienne |
| `02_boucles/` | listes, `for`, `while`, `range`, `enumerate`, Fibonacci, marche aléatoire |
| `03_conditions/` | `if` / `elif` / `else`, `break`, nombres premiers, Syracuse, recherche par dichotomie |
| `04_fichiers/` | `open`, `with`, `read` / `readline`, `tell` / `seek`, écriture de fichiers |
| `05_dictionnaires/` | dictionnaires, `.items()`, `.values()`, `continue`, tuples |
| `06_modules/` | module `sys`, arguments en ligne de commande |

Les exercices du chapitre 4 se lancent depuis le dossier `04_fichiers/` : ils lisent dans `data/` et écrivent dans `sortie/` (le contenu de `sortie/` n'est pas versionné).
