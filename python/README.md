# Python

Mes exercices de Python, rangés par chapitre. Chaque fichier ouvre un petit menu qui permet de choisir l'exercice à lancer.

```bash
cd python
python3 02_boucles.py
```

| Fichier | Notions |
|---------|---------|
| `01_affichage.py` | `print`, variables, f-strings, division euclidienne |
| `02_boucles.py` | listes, `for`, `while`, `range`, `enumerate`, Fibonacci, marche aléatoire |
| `03_conditions.py` | `if` / `elif` / `else`, `break`, nombres premiers, Syracuse, recherche par dichotomie |
| `04_fichiers.py` | `open`, `with`, `read` / `readline`, `tell` / `seek`, écriture de fichiers |
| `05_dictionnaires.py` | dictionnaires, `.items()`, `.values()`, tuples |
| `06_compter_lignes.py` | module `sys`, arguments en ligne de commande |

Les fichiers lus sont dans `data/`. Ceux que les exercices créent vont dans `sortie/`, qui n'est pas versionné.
